NEXORA CREATIVE GALLERY — ADMIN HARDENING V2

Fitur:
- Akses dashboard ditolak bila akun tidak memiliki profil admin/editor.
- Sesi logout langsung mengembalikan pengguna ke halaman login.
- Validasi format, ukuran, dan resolusi gambar.
- Optimasi JPG/PNG/WEBP otomatis ke WEBP maksimal 2560 px.
- Tampilan ukuran sebelum dan sesudah optimasi.
- Pencarian karya berdasarkan judul atau kreator.
- Filter kategori dan status Publik/Draft/Unggulan.
- Pagination 6 karya per halaman.
- Dialog konfirmasi hapus khusus yang ramah mobile.

Catatan:
- Tidak ada package npm baru.
- Tidak perlu menjalankan SQL Supabase lagi.
- Build Termux tetap menggunakan Webpack.
