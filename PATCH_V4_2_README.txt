NEXORA CREATIVE GALLERY — PATCH V4.2
LONG-PRESS DETAIL 0,6 DETIK

Fitur:
- Tahan kartu karya selama 0,6 detik untuk membuka ringkasan detail.
- Tap biasa tetap membuka halaman detail lengkap.
- Berlaku pada karya unggulan dan semua kartu galeri.
- Gerakan jari lebih dari 12 px membatalkan long-press agar scroll tetap normal.
- Getaran ringan saat ringkasan terbuka (jika perangkat mendukung).
- Background gelap + blur, animasi masuk, tombol X, dan panel dapat di-scroll.
- Menampilkan gambar, kategori, tahun, status unggulan/dilindungi, judul,
  kreator, deskripsi, kontak, serta tombol detail lengkap.
- Menu long-press browser diblokir pada kartu agar tidak bentrok.
- Proteksi selektif karya dari V4.1 tetap dipertahankan.
- Intro awal dan animasi halaman detail tetap dipertahankan.
- Petunjuk long-press hanya muncul sekali di perangkat.

Tidak membutuhkan SQL baru atau npm install.
